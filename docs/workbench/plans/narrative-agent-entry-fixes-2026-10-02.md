# Narrative 与 Agent 入口修复

Status: Implemented / Awaiting Manual Review

## 范围

- Composer 默认锁定显示，保留用户显式解锁的本地偏好。
- 角色档案提供开场消息编辑、添加及删除入口；沿用 Card 版本校验。
- Agent 面板加号打开预设选择窗口，沿用会话管理页的创建逻辑。
- Agent 面板可将当前 Timeline 中的具体 Session 设为唯一主写作接收方。

不调整认证、不改变后端路由或数据结构，不强制添加开场白，不修改其他任务文件。

## 完成标准

- 默认布局及旧布局缺省字段为锁定；显式解锁仍能恢复。
- 开场白保存通过现有 Card update；既有 Timeline 内容不随 Card 编辑改写。
- 创建对话窗口可选择预设及是否设为主写作；错误保持可见。
- 同一预设的不同 Session 不广播输入，查看 Session 不自动改变主写作。
