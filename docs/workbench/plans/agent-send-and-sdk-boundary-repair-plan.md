# Agent 发送与 AI SDK 边界修复

状态：已实现，待真实 Provider 使用验收。

## 已授权目标

修复空输出 `length` 无进展续跑、创建确认丢失、无效 Native Tool Call 诊断丢失和原生 reasoning 转换缺口。保留 Loom Runtime 的工具执行/审批/恢复所有权，以及 SDK 单次调用、零自动重试和 Abort 传播；不恢复 Provider 总轮数或单工具统一超时。

## 实现边界

- Studio 发送失败保留请求 ID，同一请求的显式重试找回原 Run；服务端校验规范化请求 SHA-256 摘要，拒绝 ID 改参。摘要进入现有检查点，通过已有 Session/Run 索引查询；不新增数据库迁移，不复制整份发送请求。
- 活跃 Run 并发查重，已完成 Run 和后台重启后的重试不会再次执行。找回已停止执行器后恢复已有暂停/历史状态，不隐式 Resume。首次持久检查点之前的准备阶段失败没有承诺持久接收。
- `length` 且没有正文/工具调用时停止，明确暴露无进展原因；保留已有正常长输出续跑。
- 保留 SDK invalid Tool Call 的诊断；坏 JSON 同样形成失败工具结果，跳过执行器，继续模型纠正。回放消息保持可编码，原调用保留在 Transcript。
- 原生 reasoning 独立流式显示和持久化，过期游标快照恢复当前思考；提交后替换临时节点，默认折叠、Replay 沿用 omit。供应商签名/思考块完整回放不在本轮范围。

## 验证

只使用本地响应模拟与临时 SQLite，不发真实模型请求。覆盖空输出只调用一次、坏参数不执行工具、complete/stream reasoning、临时到持久节点替换、过期游标快照、同请求并发/完成后重试、改参拒绝、重建 Runtime 后查回 Run。

扩大检查发现此前已有的四项失败：Native Tool Loop 的 replay 结果断言、append 冲突文案、分支编辑冲突错误码，以及 Client 的 endpoint 切换终态刷新断言。未修改这些业务语义或用新断言掩盖失败；最终类型与本轮定向检查结果见交付记录。

### 交付验证

- Gateway、Application Data、Runtime、Server 的引用构建通过；Client no-emit 类型检查通过。
- 9 文件回归：149 项通过，1 项此前已有的 endpoint 终态刷新断言失败。
- 调整索引查重与摘要持久化后，7 项定向场景复核通过，包含重建 Runtime、并发/完成后查重、无进展停止、无效工具纠正、超过八轮及快照；随后参数回放规范化的定向复核记录于同次交付。
