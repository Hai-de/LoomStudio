# Timeline 基础设施实施

状态：2026-10-20 用户授权的文件/恢复/楼号基础已实施，定向验证通过。剧情总结的三组问题保留在原计划，等 Session 总结完成后再讨论。

本次交付 Workspace、共同恢复和稳定楼号，不实现总结模型、剧情摘要扩展及其变量存储。

- application-data：Workspace 不可变树版本；Narrative 分支/节点引用；持久楼号及旧数据库迁移。
- application-runtime：Workspace 事务读写、CodeAct VFS、Swipe 候选及基线恢复、存档携带。
- studio-client：已有正文楼号展示改读持久编号。
- 验收：分支/候选和失败恢复整树；过期写入拒绝；文本/二进制存档；楼号在分页、编辑、分支中保持来源位置。

文本随树快照保存于共享 SQLite，二进制采用现有不可变 Blob Store；正文、State 与 Workspace 引用在同一事务中恢复。文件保存不增加执行权限。首版不新建文件管理 UI、不引入剧情总结策略。注入消费和 Session 总结在后续交付中接入；树版本保留文件注入元数据。

## 交付结果

- 默认 `MEMORY.md`、目录、文本和二进制引用已持久化。Runtime 提供读取、写入、移动、复制、删除；CodeAct 的 `/workspace` 复用现有读写、精确 patch、结构操作和审批，二进制内容使用宿主读写接口，单文件上限 32 MiB，与现有 Blob 读取预算对齐。
- Branch 与 Node 记录工作树版本；Swipe 基线、候选与失败恢复采用同一组正文/State/Workspace 引用。历史节点的离开点另存，分支在事务内选取完整恢复点，不再接受调用者任意指定分支的 State。
- Archive 包含工作树历史、二进制字节与恢复点；旧格式初始化独立工作区。删除 Timeline 后公共文件读写入口失效，历史存储不做物理清理。
- 持久 `floor` 接通数据库迁移、分页、正文编辑复制、分支、采样、投影及客户端楼号。楼号区间返回缺号，实际读取仍受来源身份、授权和预算约束；没有实现旧原文物理裁剪功能。

验证：相关 10 个测试文件共 96 项定向测试通过；新增覆盖旧数据库迁移、工作树恢复和分支隔离、历史二进制与旧格式存档、楼号缺口/授权、过期写入及路径身份保护。Application Data、Runtime 和 Studio Client 的 TypeScript 构建通过。未运行真实模型或浏览器验收。

后续更新：Session 自有摘要、专用总结工具、缓冲/异步与默认共享 MEMORY 消费已接线，见 [Session 总结实施](./session-summary-implementation-plan.md)。任意 Workspace 文件的被动注入配置尚未接通。文件管理 UI、脚本文件执行入口均未新增。剧情总结的三组问题保持延期，不在本次扩展设计或确定变量存储。
