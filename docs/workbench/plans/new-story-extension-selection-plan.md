# 新叙事扩展选择与当前故事面板

2026-10-19 用户确认并授权端到端实施。

## 决定

- 开始新叙事时统一显示扩展选择弹窗，默认选择当前已启用且适用于目标角色 / Timeline 的扩展。
- 用户的本次选择直接随创建请求提交，在新 Timeline 创建事务中采用并初始化，不先修改角色默认配置，不创建后逐个补写。
- 未就绪安装须显示具体原因，不自动覆盖作者资源、放宽权限或修改旧故事。
- 当前故事面板复用 Dialog、Button、Checkbox 与已有 Tab；动作显示名称，技术来源放进次要信息。
- 当前故事使用 Timeline 绑定的角色作为上下文，不使用角色编辑器里残留的选中对象。

## 范围

主 Agent 实施创建请求 / 弹窗接线、当前故事控件和角色上下文修复。保留其他任务已有修改；不在本轮改变 The World 变量默认值或自动恢复契约。

## 验收

所有新故事入口经过同一弹窗；取消不创建、不改角色；取消勾选确实不采用；确认后创建事务保留选择。切换角色后左侧包内容和故事默认使用正确角色；当前故事的控件具备明确名称和统一组件样式。

## 实施结果

- 新叙事选择位于 `new-story-extensions.tsx`，所有创建入口复用 Narrative hook；取消不产生写入。
- `createNarrativeTimeline.extensionAdoptions` 为本次创建覆盖项；省略时保留原 API 的角色默认行为，显式空数组不采用扩展。
- 当前故事面板仅管理当前故事，新故事选择统一进入创建弹窗；控件采用共享 UI，来源详情折叠。
- 扩展面板角色上下文独立读取 Timeline 来源角色，切换期间不回退显示其他角色；故事视图不显示包管理树。
- 已执行定向类型构建及创建 / 面板用例；主观布局与交互手感由用户验收。本轮不自动创建真实故事或更改现有故事默认配置。
