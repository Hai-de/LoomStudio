# Agent 审批与中断恢复

状态：已实现，待真实 Session 验收。

## 已确认范围

审批预览关闭或刷新后可从当前 Session 重新打开。Agent Preset 按范围设置每次询问、自动允许或禁止；缺省保持现有行为。策略作用于已有 VFS 写入、历史读取和作者模式审批点，不扩大数据访问，也不替代 Tool Mount/Registry 权限；剧情追加等不经过这些审批点的操作不新增审批。

## 实现与恢复边界

- 服务端订阅持续携带待审批快照；客户端只展示队首请求，隐藏不等于拒绝，刷新后对存活 Run 重新订阅。
- Session 恢复使用服务端状态；观察断连不等于暂停。放弃遇到真实执行中状态时恢复观察，保留停止入口。
- 状态检查及冷启动放弃与继续执行的完整检查点验证分离。确认执行器停止、CAS 成功后允许放弃；未知工具副作用仍禁止自动重放。
- 审批回调先检查取消信号，避免先取消后申请审批的等待悬挂。
- 已结束或暂停任务的无结果工具卡显示“已中断”，不伪造执行结果或回滚副作用。
