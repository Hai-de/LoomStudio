# Agent Preset 模型选择弹窗

状态：已实现，待用户体验验收。

## 已确认事实与决定

预设保存 `providerProfileId + modelId`，运行时要求模型出现在账号的 `enabledModelIds` 中。本次保留此合同，不迁移存储，不移除账号页的模型管理。

模型选择改为搜索弹窗，按提供商账号分组，展示账号图标、已添加模型和现场获取的目录。搜索匹配账号名与模型 ID；同一搜索框也允许输入精确模型 ID 手动添加。当前绑定始终单独可见，列表读取失败不影响已保存绑定。

获取目录不持久化；点击未添加模型时，先复用 `createModelProfile`，成功后再保存预设。保存成功关闭弹窗；失败保留弹窗与错误，已成功添加的模型不回滚。保存期间禁用关闭和重复提交，目录请求按账号独立加载、失败可重试。

## 实施边界

- `agent-model-picker.tsx/module.scss`：展示、搜索、账号目录读取状态；不直接调用 RPC。
- `agent-model-editor.tsx`：绑定保存与先添加后绑定的顺序、版本冲突和部分成功反馈。
- PresetWorkbench / App：传递既有获取、添加回调。
- i18n：同步四种语言。

## 验收

已添加模型直接绑定；未添加模型先添加再绑定；添加失败不保存预设；绑定失败不显示为成功。覆盖搜索分组、目录重试、手动 ID 与自动保存版本冲突；定向测试及 Client 类型检查。视觉由用户体验验收，不发送真实模型请求。

## 实施结果

弹窗与预设保存流程已接通，复用账号模型添加和目录读取回调，覆盖四种语言。Client 类型检查通过；模型选择与预设集成的 10 项定向测试通过，Sass 编译通过。未发起真实提供商请求，未进行浏览器视觉验收。
