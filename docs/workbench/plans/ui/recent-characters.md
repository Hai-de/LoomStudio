# Dock 最近角色

2026-10-15 用户确认：Dock 快速切换角色，顶部 Timeline 胶囊负责故事切换。

- 每个角色仅一条，两行显示角色名及上次故事标题；取消日期分组、更新时间和正文片段。
- 按导航成功后的实际访问顺序记录，包含 Timeline 与分支，按浏览器 origin 和服务端 endpoint 隔离。最多保留 24 个角色，Dock 展示前 8 个仍存在的角色。
- 不从更新时间回填历史，旧用户从本次开始积累访问记录。后台更新不重新排序。
- 点击时重新读取角色故事目录及目标分支；删除的目标回到该角色开始界面，由顶部入口选择故事，不替用户自动选最新故事。网络失败显示错误，不当作目标删除。
- 无故事时进入开始界面，不创建 Timeline。仅浏览开始界面不会覆盖之前成功进入的故事记录。
- 原完整“最近”面板保持历史浏览职责；本次调整 Dock 下拉与按钮文案。

## 验证

客户端类型检查通过；访问顺序去重、精确故事/分支记录、开始界面保留记录及 endpoint 隔离共 3 项测试通过。未执行浏览器端到端切换验收，视觉由用户验收。
