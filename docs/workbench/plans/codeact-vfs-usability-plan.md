# CodeAct / VFS 使用契约补齐

状态：已实现，本地定向验证通过，待真实模型体验。

## 用户确认的范围

依据用户提供的内部 Agent 实测反馈，补 State 结构化读取与类型保护、统一回执、明确错误与目录分页、改善字面搜索片段，并修订默认工具说明。不改角色 State 数据、Workspace MEMORY 或设定内容，不增加宿主文件或历史访问权限。

## 契约

- `readValue(path)` 只读 State 值文件，返回完整 JSON 值，与同路径 write 共用完整读取、Revision 和权限校验；序列化 JSON 限 16384 字符，过大拒绝，不返回残缺对象。
- State 对象/数组被替换为其他类型需 `allowTypeChange: true`。显式类型变化仍须通过审批、CAS 和领域 Schema；不自动解析字符串，不在文本资源接收该选项。
- ls 默认文本保留，JSON 格式输出完整路径、类型、状态和分页信息；文本区分空目录与无更多结果。不新增递归树或路径转义 helper。
- search 仍是限定范围的字面检索，显示命中词和多个位置，每文件最多六行，保留行号及省略标识。
- 所有写/结构操作回执统一 JSON 对象；State patch 优先报能力不支持。
- 说明区分探索型 allSettled、依赖型顺序 await；写入即时生效，不可通过脚本失败回滚，不在真实状态上做写入探测。
